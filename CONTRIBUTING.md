# Feedback and Suggestions

Thank you for your interest in BringYourSub!

## About This Project

This is a personal project developed and maintained by a single developer. While I'm not accepting pull requests or direct contributions at this time, I greatly appreciate feedback and suggestions from the community.

## How to Share Feedback

If you have:

- **Bug Reports** - Found something broken? Please open an issue!
- **Feature Requests** - Have an idea for improvement? I'd love to hear it!
- **General Suggestions** - Any other feedback is welcome

### Opening an Issue

1. Go to the [Issues](https://github.com/Vartmor/bringyoursub/issues) page
2. Click "New Issue"
3. Provide a clear title and detailed description
4. Include steps to reproduce (for bugs) or use cases (for features)

## Contact

For direct inquiries, you can reach me through GitHub issues.
