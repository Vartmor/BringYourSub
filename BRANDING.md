## 📐 Logo Gereksinimleri

### Extension Icons (Required)
| File | Size | Format | Notes |
|------|------|--------|-------|
| `icon16.png` | 16x16 px | PNG | Toolbar, small displays |
| `icon32.png` | 32x32 px | PNG | Toolbar, standard |
| `icon48.png` | 48x48 px | PNG | Extensions page |
| `icon128.png` | 128x128 px | PNG | Chrome Web Store, about |

### Design Requirements
- **Clear on dark backgrounds** - Primary usage is on dark YouTube interface
- **Recognizable at 16px** - Must be legible at smallest size
- **No text at small sizes** - Only icon element
- **Consistent with brand colors** - Use primary gradient

### Logo Concept Ideas
1. **Subtitle bubble** - Speech bubble with text lines
2. **Translation arrows** - A → B style
3. **Key + subtitles** - Representing BYOK concept
4. **Film + AI** - Representing video AI

## 🗣️ Voice & Tone

### Messaging Principles
1. **Professional but approachable** - Not corporate, not casual
2. **Technical but not intimidating** - Explain concepts simply
3. **Privacy-focused** - Emphasize BYOK and data security
4. **User-empowering** - "Your key, your control"

### Taglines
- Primary: **"AI YouTube Subtitles with Your API Key"**
- Secondary: **"Privacy-First Subtitle Generation"**
- Short: **"BYOK Subtitles"**

### Key Messages
- ✅ "Your API key never leaves your device"
- ✅ "No server - direct to AI provider"
- ✅ "Zero data collection"
- ✅ "Choose your AI provider"
- ✅ "Support for 7+ AI providers"

---

## ✅ Do's and Don'ts

### Do
- Use the official color palette
- Maintain clear space around the logo
- Use Inter font for all materials
- Emphasize privacy and BYOK benefits
- Show the extension in context (YouTube)

### Don't
- Stretch or distort the logo
- Use colors outside the palette
- Add effects (shadows, glows) to the logo
- Claim features that don't exist
- Show real user data in screenshots
